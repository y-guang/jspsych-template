# Project Setup

## init vite project

Init a new Vite project with the following options:

```bash
pnpm create vite
Vanilla
TypeScript
```

## clean up the vite template

remove everything unnecessary from `src` and `index.html`

## setup hello world

install the dependencies.

```bash
pnpm add @jspsych/plugin-html-keyboard-response
pnpm add -D terser
```
